
# SM Fisheries – Fish Buying and Selling Portal

## About the Project
SM Fisheries is a web-based project designed to support fish buying and selling through an online portal.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- SQL
- XAMPP
- Visual Studio Code

## Tools Required
- XAMPP
- Visual Studio Code
- Web Browser

## How to Run the Project
1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Place the project folder inside the XAMPP `htdocs` folder.
4. Import the database into phpMyAdmin, if a database file is available.
5. Configure the database connection if required.
6. Open the project in your browser using `http://localhost/your-folder-name/`.
